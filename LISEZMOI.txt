Mon Budget - version en fichiers séparés
=======================================
index.html  structure de la page
style.css   styles (thème clair/sombre automatique)
app.js      toute la logique (import, catégories, projection, enveloppes...)
shim.js     remplace les fonctions propres à claude.ai quand la page est hébergée ailleurs

Utilisation : héberger les 4 fichiers dans le même dossier (serveur web, GitHub Pages, Raspberry Pi...),
ou lancer en local :  python3 -m http.server 8000   puis ouvrir http://localhost:8000

Différences avec la version claude.ai :
- Pas de partage familial en temps réel : les données restent dans le navigateur de chaque appareil
  (utiliser Réglages > Exporter la sauvegarde / Restaurer pour les déplacer).
- Le lecteur Excel (SheetJS) est chargé depuis cdnjs.cloudflare.com : prévoir une connexion internet.
- Le code de verrouillage n'est qu'une protection d'ouverture, pas du chiffrement.
